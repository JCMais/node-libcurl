# Security Policy

## Supported Versions

Only v5 is supported. Security updates for supported versions are released as minor version increments.

| Version | Supported          |
| ------- | ------------------ |
| 5.x     | :white_check_mark: |
| < 5.0.0 | :x:                |

We may backport a fix to the immediately previous major version for a serious
security vulnerability when affected users have no practical workaround.
Building from source with a patched dependency may be a workaround when feasible.

## Reporting a Vulnerability

This project uses Tidelift security advisory, please see https://tidelift.com/security for details on how to report possible security vulnerabilities.
